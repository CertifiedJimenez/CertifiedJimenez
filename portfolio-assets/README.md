# Local portfolio preview

Open `../index.html` directly, or serve the repository with `python3 -m http.server 4173 --bind 127.0.0.1`.
`../portfolio.html` is a self-contained version with fonts, styles, scripts and the image embedded. Rebuild it with `python3 scripts/build-portfolio-html.py` from the repository root.

The reference is https://www.crrtt.com/ (retrieved 23 November 2026). Its layout, SVG artwork, five font faces, and animation bundle are retained for this local design preview. The font counter and obsolete external polyfill requests are removed. The animation bundle has one content change: the technology-stack toggle resets to “stack”.

Personalization: Cristofer Jimenez, London, software engineer, contact address and technologies from the existing repository; project names and summaries from https://www.linkedin.com/in/cristofer-jimenez and the public https://github.com/CertifiedJimenez/drivelog repository. Project links for LinkedIn entries open the profile's Projects section. Original awards, clients and personal biography have been replaced.

The wordmark uses outlines from the reference's Classic Roman font, preserving its SVG letter animation. The hero illustration, entrance sequence, mouse perspective, smooth scroll, project hover emblems, light theme and alternate artwork are retained. Original design credit is preserved in the footer.

This is a local preview. No site has been published.
