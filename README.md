# Cristofer Jimenez

I’m a software engineer in London. I build backends with Python and Django, interfaces with React, and tools for people working with data. My projects range from matching CVs to jobs to recording where a learner driver picked up a fault.

[Portfolio](https://cristoferjimenez.com/) · [LinkedIn](https://www.linkedin.com/in/cristofer-jimenez) · [Email](mailto:contact@cristoferjimenez.com)

## Selected work

- **[DriveLog](https://github.com/CertifiedJimenez/drivelog)** lets a driving instructor mark a mock test on a phone, capture the location of each fault, and share the results with the learner.
- **AI Job Board** uses Flask and AI to match CVs to job listings.
- **Portfolio Tracker** connects Django with MetaTrader for trade journaling.

The [full portfolio](https://cristoferjimenez.com/#projects) includes my TikTok CMS and algorithmic trading work. The [development guide](https://github.com/CertifiedJimenez/CertifiedJimenez/blob/main/docs/development.md) covers how to run, edit, and build the site.
